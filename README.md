# ESP32 C++ Samples

These are samples I am coding as I learn about ESP32 topics on my own. I am planning to experiment with the ESP32, and this repository is where I will rehearse ideas along the way.

## Samples

- [SPSC ring buffer](spsc_ring_buffer/README.md): A lock-free single-producer/single-consumer ring buffer demo that simulates an ESP32-style producer ISR with a thread and an audio-processing consumer with another thread.

More samples will follow.

To encourage other developers to join the ESP32 army, these samples do not require a real ESP32 to run. The goal is to rehearse embedded systems design and architecture techniques rather than write code for the specific SoC itself.
